# Demo Çiçekçim

Çiçek ve hediye ürünleri için hazırladığım bir vitrin sitesi. Ürünleri inceleme, kategori ve arama üzerinden gezme, favorilere ekleme ve sepetten WhatsApp'a sipariş talebi gönderme akışı bulunuyor.

## Canlı demo

- [Node.js sürümü](https://cicekdemo.tasarlayalim.com/node-js-version/)
- [HTML sürümü](https://cicekdemo.tasarlayalim.com/html-version)

İki sürüm de mevcut demo adresinde yayınlanıyor. Ürünler ve fiyatlar örnek amaçlı; çevrimiçi ödeme alınmıyor.

## Özellikler

- Ürün listesi, kategori ve ürün detay sayfaları
- Arama, favoriler ve sepet
- WhatsApp üzerinden sipariş talebi
- Mobil ve masaüstü düzenleri

## Kaynak kod

Yayınlanan Node.js ve HTML sürümleriyle birlikte hazırlanan Cloudflare Workers dağıtım paketi ayrıca mevcut. Kaynak dosyalar bu repoya henüz aktarılmadığı için buradaki README tek başına yerel kurulum sağlamıyor.
